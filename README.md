# Mobile Security CTF challenges

Android (and iOS) mobile CTF challenges collected from public CTF competitions.

**76 CTFs · 190 challenges · 187 APK · 6 IPA · 1 AAB**

## Layout

Challenges follow `<CTF>/<YEAR>[/<stage>]/<category>/<challenge>/` (e.g. `BSidesSF/2023/rev/space-cowboy/`).
Each challenge folder holds the binary plus any author notes (`README.md`), sources or companion files.
Known exceptions: `StarCTF/2019` and `TAMUctf/2019` keep binaries flat in the event folder;
`Urmia/2023/forensic/Deleted_Message` keeps only the challenge file `the.apk` from the original emulator dump.
Description below is the challenge author's own first line where present, otherwise blank.
